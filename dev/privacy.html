JSON Diver — Privacy Policy

Last updated: 16 September 2026 · 最終更新: 2026年9月16日
English · 日本語

English

JSON Diver does not collect, store or transmit any personal information. There is no account, no sign-in, no analytics and no advertising. The application works fully offline, and the JSON you open stays on your device.

What the application does with your data

  • JSON documents and schemas. Content you paste, drop or open is processed entirely on your device, in memory and in local storage belonging to the application. It is never uploaded anywhere.
  • Local storage. So that your work is still there next time, the current document and any JSON Schema you entered are saved locally on the device. The Clear button removes the document, and emptying the schema box removes the schema. Uninstalling the application removes its local storage.
  • Files. The application reads and writes only the files you choose — a file you open, drop onto the window, or save with Ctrl+S. It does not scan or index your file system.
  • Clipboard. The optional Watch feature is off by default. While you switch it on, the application reads clipboard text so that JSON copied in another application can be displayed. Clipboard contents are used only to render the document on screen; they are not stored separately and never transmitted.

Network use

The desktop application makes no network requests of its own. The only outbound action is opening a link you click in the sidebar — the project website or its GitHub page — in your default browser.

The browser edition at json.kintoys.app is static hosting: the page and its script are downloaded once and everything then runs in your browser. No JSON you load is sent to the server. As with any website, the hosting provider (Cloudflare) processes standard technical request data such as your IP address in order to deliver the page; see Cloudflare's privacy policy.

Third parties and children

No data is shared with third parties, because none is collected. The application is not directed at children and collects no information from anyone, regardless of age.

Changes and contact

If this policy changes, the updated version will be published at this address with a new date. Questions and privacy enquiries: github.com/motohasystem/json-diver/issues.

日本語

JSON Diver は個人情報を収集・保存・送信しません。 アカウントもサインインも不要で、解析ツールも広告も使用していません。完全に オフラインで動作し、開いた JSON はお使いの端末から出ません。

アプリが扱うデータ

  • JSON とスキーマ。 貼り付け・ドロップ・ファイルから読み込んだ 内容は、すべて端末内（メモリとアプリのローカルストレージ）で処理されます。 外部へアップロードすることはありません。
  • ローカルストレージ。 次回の作業を再開できるよう、表示中の ドキュメントと入力した JSON Schema を端末内に保存します。Clear ボタンで ドキュメントを、スキーマ欄を空にすればスキーマを削除できます。アプリを アンインストールすればローカルストレージも削除されます。
  • ファイル。 読み書きするのは、お客様が選んだファイル（開いた ファイル、ウィンドウにドロップしたファイル、Ctrl+S で保存する先）だけです。 ファイルシステムの走査や索引付けは行いません。
  • クリップボード。 任意機能の Watch は既定で OFF です。 ON にしている間だけ、他のアプリでコピーされた JSON を表示するためにクリップ ボードのテキストを読み取ります。読み取った内容は画面への描画にのみ使用し、 別途保存することも、送信することもありません。

ネットワークの利用

デスクトップ版はアプリ自身によるネットワーク通信を行いません。外部へ出る動作は、 サイドバーのリンク（プロジェクトのウェブサイトまたは GitHub ページ）をクリック した際に、既定のブラウザで開くことだけです。

ブラウザ版 json.kintoys.app は静的配信です。 ページとスクリプトを最初に取得した後は、すべてブラウザ内で動作します。読み込んだ JSON がサーバーへ送られることはありません。なお一般的なウェブサイトと同様に、 ホスティング事業者（Cloudflare）がページ配信のために IP アドレスなどの技術的な リクエスト情報を処理します。詳細は Cloudflare のプライバシーポリシーをご参照ください。

第三者提供と児童について

そもそもデータを収集していないため、第三者への提供もありません。本アプリは児童を 対象としたものではなく、年齢にかかわらず、いかなる利用者からも情報を収集しません。

変更と問い合わせ

本ポリシーを変更した場合は、更新日を改めてこのアドレスで公開します。ご質問・ プライバシーに関するお問い合わせ: github.com/motohasystem/json-diver/issues
