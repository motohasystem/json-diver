## 製品名

JSON Diver

## 短い説明（500 文字以内）

JSON を階層ツリーで読み・編集するビューア／エディタ。自分で書いた JSON ではなく、
「読まされる JSON」のための道具です。数百行、深い階層、値の中に文字列として
埋まったさらなる JSON — そういうものを相手にします。

## 説明（10,000 文字以内）

JSON Diver は、**読まされる JSON** のためのビューア／エディタです。API のレスポンス、
エクスポートされたダンプ、ログのペイロード、誰かが 2 年前に圧縮した設定ファイル。
自分で書いた整った JSON ではなく、そういうものを開くための道具です。

JSON を階層ツリーとして描画するので、構造は「括弧を数えて組み立てるもの」ではなく
「見えるもの」になります。深さごとに開閉し、ミニマップで俯瞰し、エスケープを手で
戻すことなく、文字列の中の JSON まで読めます。

**エスケープされた JSON に潜る**

アプリ名の由来になっている機能です。値が JSON 文字列 — どの API でも最終的に必ず
出てくるあの `"{\"key\":\"value\"}"` — のとき、自動的に検出してマークします。
ホバーすれば中の構造をプレビュー、クリックすれば独立したウィンドウで完全なツリーと
して開きます。エスケープ JSON の中にさらにエスケープ JSON が入っていても大丈夫です。
ビューが階層的に重なり、それぞれに深さが表示されます。アンエスケープ用のサイトに
貼り付ける必要も、元の場所を見失うこともありません。

**細部より先に全体像を**

ツリーの上のバーには、深さごとの開閉ボタンが並びます。各ボタンにはその深さにある
オブジェクト／配列の個数が出ます。「深さ 2 まで開いて全体を俯瞰し、必要な枝だけ
掘る」という読み方ができます。折りたたんだオブジェクトにホバーすれば、展開せずに
中身のミニツリーが見えます。サイドバーのミニマップは文書全体を型ごとに色分けした
俯瞰図にし、クリックすればその位置へ飛べます。

**その場で編集、あるいはテキストとして編集**

3 つのモードを 1 つのスイッチで切り替えます。

- **View** — 閲覧・コピー・ズームに専念
- **Edit** — 値をクリックしてその場で編集。行のハンドルをドラッグして、ノードを
  別のノードの前・中・後ろへ移動
- **Raw** — 生の JSON テキスト。手で打ったほうが速いときのために

どのモードで加えた変更も Ctrl+Z で取り消せます。

**JSON Schema で検証**

サイドバーにスキーマを貼り付けると、表示中のデータがその場で検証されます。違反した
行はツリー上で赤くハイライトされ、理由はホバーで確認できます。ツールバーのバッジを
押せば最初の違反へジャンプし、Edit モードでは違反が増えるドラッグ移動を着地前に
ブロックします。対応キーワードは type / const / enum / properties /
patternProperties / additionalProperties / required / items / prefixItems /
minItems / maxItems / oneOf / anyOf / 内部参照の $ref です。

**クリップボードを監視**

Watch を ON にすると、どのアプリでコピーした JSON でも自動的に読み込まれます。
ウィンドウを切り替える必要も、貼り付け操作も要りません。拾うのはオブジェクトと配列
だけ、同じ内容を二度読み込むことはなく、直前の表示内容には常に Ctrl+Z で戻せます。

**Windows のための作り**

- `.json` ファイルをダブルクリックで開く（ファイルの種類を関連付けた後）
- **Ctrl+S** で元ファイルへ直接上書き保存（UTF-8 / BOM なし）
- 別の `.json` は新しいウィンドウで開く。**Ctrl+N** で空のウィンドウ
- ウィンドウにファイルをドラッグ＆ドロップすると、パスを保持したまま開くので
  そのまま保存できる

**大きな JSON でも軽快に**

子要素が 50 件を超えるコンテナは、まず 50 件だけ描画し、残りはスクロールに応じて
読み込みます。数万行のファイルでも、小さなファイルと同じように開いてスクロール
できます。

**データは手元から出ません**

アカウント不要、サインイン不要、テレメトリなし、どこにもアップロードしません。
JSON Diver は完全にオフラインで動作し、読み込んだ内容は消すまでこの端末のローカル
ストレージに留まります。ネットワークに触れるのは、サイドバーの 2 つのリンクを
クリックして既定のブラウザで開くときだけです。

JSON Diver はオープンソースです。ソースコード・不具合報告・リリースノート:
https://github.com/motohasystem/json-diver

## アプリの機能（最大 20 項目）

1. JSON を階層ツリーで表示。型ごとのアイコンと要素数付き
2. 文字列としてエスケープされた JSON を自動検出してマーク
3. エスケープ JSON を独立ウィンドウで完全なツリーとしてズーム表示
4. エスケープ JSON の入れ子にも対応。階層ごとに深さバッジを表示
5. 深さごとの開閉ボタン。各深さにあるコンテナの個数を表示
6. 折りたたんだオブジェクト／配列にホバーして中身をミニツリーでプレビュー
7. 文書全体を型別に色分けしたミニマップ。クリック／ドラッグで目的の位置へ
8. 文字列・数値・真偽値のインライン編集
9. ドラッグ＆ドロップでノードを移動（前に挿入／中に入れる／後ろに挿入）
10. あらゆる編集に対する取り消し・やり直し（Ctrl+Z / Ctrl+Shift+Z）
11. Raw モードで JSON をテキストとして直接編集
12. Pretty トグル。2 スペース整形と 1 行圧縮を全体に一括適用
13. JSON Schema による逐次検証。違反箇所をツリー上でハイライト
14. スキーマ違反が増えるドラッグ移動を事前にブロック
15. クリップボード監視。どのアプリでコピーした JSON も自動で読み込み
16. ファイルの種類を関連付ければ `.json` をダブルクリックで起動
17. Ctrl+S で元ファイルへ UTF-8 / BOM なしで上書き保存
18. ファイルごとに別ウィンドウ。Ctrl+N で空の新規ウィンドウ
19. 任意のノード、または文書全体をワンクリックでクリップボードへコピー
20. 完全オフライン動作。アカウント不要・テレメトリなし・データは端末外に出ません
